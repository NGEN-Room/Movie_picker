# Command line
1. top left menu open terminal
2. Use Bash terminal (click the down arrow next to the plus sign)
3. Find your directory 
4. navigate to Movie_picker/movie-picker (cd folder_name)
5. start process below

# First load
once terminal is in the movie-picker folder run these commands:

```
npm install
```
this will install all dependacies

and then to run a dev instance run:
```
npm run dev
```
on success find it on: http://localhost:3000/
