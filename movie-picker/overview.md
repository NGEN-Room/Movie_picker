# Movie Picker 🎬

Movie Picker helps groups decide on a movie without the usual arguments. Users answer a short preference quiz, rate movie options, and the app recommends the best movie for the group.

## Goal

Reduce decision fatigue and help groups quickly find a movie everyone is happy to watch.

## Features

- Group movie voting
- Preference-based recommendations
- Tinder-style movie selection
- Tracks watched movies and rewatch preferences
- Generates the top 5 movie recommendations
- Group ranking system to select a final movie

## User Flow

1. Users join a movie session.
2. Complete a multiple-choice preference quiz.
3. Indicate:
   - Movies they've seen
   - Movies they'd watch again
   - Movies they're not interested in
4. Swipe through suggested movies.
5. Receive 5 recommended movies.
6. Rank the recommendations.
7. App selects the best overall movie for the group.

## MVP

- Preference quiz
- Movie recommendation engine
- Top 5 movie suggestions
- Group ranking system
- Final movie selection
